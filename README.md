# Zapret Automated Configurator & Network Patcher

Автоматизированный скрипт для корректной интеграции списков маршрутизации и тонкой настройки параметров фрагментации TCP/UDP пакетов в утилите **zapret** (winws.exe). Оптимизирован для устранения задержек, сбросов соединений и медленной буферизации статического/потокового медиа-контента.

## 🚀 Возможности
* **Автоматическая синхронизация таблиц хостов:** Интеллектуальный импорт данных в `list-general-user.txt` и `list-exclude-user.txt`. Скрипт автоматически создает файлы при их отсутствии или дописывает новые сетевые узлы в конец структуры без повреждения существующих записей.
* **Модификация сетевых профилей:** Находит целевой `.bat` сценарий и адаптирует параметры десинхронизации под стек `fake,fakedsplit` с паттерном `0x00`, восстанавливая штатный отклик веб-интерфейсов и AJAX-запросов.
* **Защита от сброса путей:** Скрипт корректно обрабатывает относительные пути при вызове из привилегированного режима Windows (запуск от Администратора).

## 📦 Содержимое репозитория
* `full_installer.bat` — интерактивный консольный сценарий настройки.
* `list-general-user.txt` — пользовательский перечень сетевых адресов и CDN для оптимизации доставки медиа-контента.
* `list-exclude-user.txt` — список магистральных CDN-серверов исключений (для сохранения максимальной пропускной способности при скачивании дистрибутивов).

## 🛠️ Инструкция по использованию

### Шаг 1. Подготовка компонентов
1. Скачайте файлы `full_installer.bat`, `list-general-user.txt` и `list-exclude-user.txt` из данного репозитория.
2. Разместите все три файла в **одной общей папке** в любой директории вашего накопителя.

### Шаг 2. Инициализация конфигуратора
1. Нажмите правой кнопкой мыши на файл `full_installer.bat` и выберите **«Запуск от имени администратора»**.
2. В консольном интерфейсе укажите целевой путь к корневой директории установленной утилиты `zapret` (каталог можно перетащить мышью непосредственно в окно терминала) и нажмите `Enter`.
3. Введите точное имя обрабатываемого конфигурационного файла сценария (например, `alt1.bat` или `general.bat`) и нажмите `Enter`.

### Шаг 3. Применение параметров и сброс кэша
После успешного завершения работы конфигуратора:
1. Запустите измененный `.bat` файл из папки утилиты от имени Администратора.
2. Откройте Steam → \*\*Настройки\*\* → \*\*Загрузки\*\* → нажмите кнопку \*\*«Очистить кэш загрузки(Очистить кэш)»\*\* (это очистит зависшие битые сессии кэша).
3. В веб-браузере выполните жесткую перезагрузку страниц со сбросом кэша сетевых скриптов с помощью комбинации клавиш **`Ctrl + F5`**.

## ⚠️ Системные требования
* Операционная система Windows 7 / 10 / 11 (x64).
* Запуск скрипта автоматизации строго с правами **Администратора**.
