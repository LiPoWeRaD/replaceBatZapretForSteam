\# Zapret Custom Installer \& Auto-Patcher



Автоматизированный скрипт-инсталлятор и конфигуратор для утилиты \*\*zapret\*\* (winws.exe), оптимизированный специально для обхода замедлений и блокировок \*\*Steam (Магазин, Картинки, Видео, Сообщество), YouTube и Discord\*\* на сетях провайдера \*\*Ростелеком\*\*.



\## 🚀 Возможности

\* \*\*Умная синхронизация списков:\*\* Скрипт проверяет наличие файлов `list-general-user.txt` и `list-exclude-user.txt` внутри каталога утилиты. Если файлов нет — создает их, если есть — дописывает новые домены в конец.

\* \*\*Авто-модификация стратегии:\*\* Находит указанный `.bat` сценарий внутри zapret и автоматически заменяет устаревшую строку обработки на актуальную и стабильную стратегию `fake,fakedsplit` с паттерном `0x00`.

\* \*\*Исправление рабочей директории:\*\* Скрипт защищен от сброса путей Windows при запуске от имени Администратора (`cd /d "%\~dp0"`).



\## 📦 Содержимое репозитория

\* `full\_installer.bat` — основной исполняемый интерактивный скрипт.

\* `list-general-user.txt` — кастомный дополняемый список доменов для разблокировки медиа-контента.

\* `list-exclude-user.txt` — список CDN-адресов исключений (чтобы не резать скорость скачивания самих игр).



\## 🛠️ Инструкция по использованию



\### Шаг 1. Подготовка файлов

1\. Скачайте файлы `full\_installer.bat`, `list-general-user.txt` и `list-exclude-user.txt` из этого репозитория.

2\. Поместите их все три в \*\*одну отдельную папку\*\* на вашем компьютере (в любое удобное место).



\### Шаг 2. Запуск установки

1\. Нажмите правой кнопкой мыши на файл `full\_installer.bat` и выберите \*\*«Запуск от имени администратора»\*\*.

2\. В появившемся окне консоли укажите полный путь к вашей основной папке `zapret` (папку с оригинальной утилитой можно просто перетащить мышкой прямо в окно терминала) и нажмите `Enter`.

3\. Введите точное имя исполняемого `.bat` файла внутри zapret, который вы запускаете для обхода (например, `alt1.bat` или `discord.bat`) и нажмите `Enter`.



\### Шаг 3. Финализация в Steam / Браузере

После успешного завершения работы инсталлятора:

1\. Запустите ваш измененный батник из папки `zapret` от имени Администратора.

2\. Откройте Steam → \*\*Настройки\*\* → \*\*Интерфейс\*\* → нажмите кнопку \*\*«Удалить данные браузера»\*\* (это очистит зависшие битые сессии кэша).

3\. Если используете браузер, обновите страницу сообщества Steam сочетанием клавиш \*\*`Ctrl + F5`\*\*.



\## ⚠️ Требования

\* Операционная система Windows 7/10/11 (64-bit).

\* Запуск строго с правами \*\*Администратора\*\*.
